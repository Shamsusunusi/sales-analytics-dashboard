# sales-analytics-dashboard
Interactive sales analytics dashboard for tracking revenue, sales performance, customer trends, product performance, and key business KPIs.

# Project Overview

This project presents an interactive Sales Performance Dashboard built in Microsoft Excel. 
The dashboard provides a consolidated view of sales, profit, customers, orders, and average order value.

It allows users to explore business performance across different years, product categories, 
customer segments, regions, and individual customers. The dashboard was designed to transform 
raw sales data into actionable business insights through interactive visualizations and KPIs.

# Business Objective

The objective of this project was to develop an interactive reporting dashboard 
that enables stakeholders to quickly monitor sales performance and identify key 
business trends.

The dashboard was designed to answer questions such as:

- What are the overall sales and profit levels?
- How does sales performance change over time?
- Which product categories generate the most sales?
- Which regions contribute the most revenue?
